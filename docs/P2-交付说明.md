# P2 交付说明：Vue 3 本地管理前端

## 阶段结论

P2 已完成。项目现在通过 `main.py` 同时提供 FastAPI 接口和 Vue 3 生产页面，不需要单独启动前端开发服务。

## 已交付页面

- 首次运行创建唯一的本地管理员，后续使用同一布局登录。
- 控制台展示账号、任务、支付和 Worker 摘要。
- 任务中心支持筛选、创建、取消、重试、详情事件和一次性输入。
- GoPay 账号页展示公开状态并可创建余额刷新任务。
- 支付管理页仅展示 Midtrans 公开摘要，不返回 Snap 哈希和加密原文。
- 设置页展示 SQLite WAL、数据库完整性、Worker 池、本地安全边界和 Handler 列表。

## 布局与主题

整体结构参考 `iCloud-Privacy-Mail-v2`：桌面端左侧固定导航、移动端抽屉、顶部状态栏和内容工作区。左侧导航底部和顶部均有太阳/月亮主题按钮，主题选择保存在浏览器本地存储，首次访问跟随系统设置。

## 实时数据

页面共享 SSE 连接。账号、任务或支付摘要变化时，对应页面按资源类型节流刷新；断线后按 `Last-Event-ID` 续传，页面显示连接、重连或断开状态。

## 验证

- Vue 生产构建成功，构建结果复制到 Python 包内的 `web_dist`。
- SPA History 回退、登录跳转和 API 404 边界有自动化测试。
- 支付公开摘要接口经过敏感字段泄露测试。

## 下一阶段

P3 将实现 GoPay 注册、已有账号登录、SMSBower 自动取号取码、OTP 暂停/恢复、PIN 设置与修改。
