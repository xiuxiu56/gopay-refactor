# P4 交付说明：Midtrans 与 GoPay 可恢复支付

## 阶段结论

P4 已完成。Midtrans Snap 支付链接、GoPay 支付执行、支付 OTP、PIN 授权、远端结果核验与人工复核已接入 SQLite 持久化任务队列。支付流程由固定 Worker 池执行，等待 OTP 时释放 Worker，收到页面输入后从 AES-GCM 加密检查点继续。

## 任务类型与接口

- `payment.execute`：租用支付账号与 Snap 资源，恢复 Cookie 和检查点，执行 OTP、PIN 授权、扣款及远端状态核验。
- `payment.reconcile`：只读取 Midtrans 远端状态，不重复提交扣款请求。
- `POST /api/v1/payments`：解析并加密保存 Snap 链接，选择支付账号并创建执行任务。
- `GET /api/v1/payments`：按状态查询支付公开摘要。
- `POST /api/v1/payments/{id}/reconcile`：为支付意图创建只读复核任务。
- Vue“支付管理”工作台：创建支付、选择账号、覆盖 PIN、提交 OTP、发起复核并实时显示结果。

## 可恢复与副作用边界

支付检查点记录当前协议阶段、账号、Snap、Cookie、短信激活记录和已消费验证码哈希。链接、PIN、Cookie 与远端原始状态均以 AES-GCM 加密保存；页面 API 只返回订单号、金额、状态和错误摘要。

扣款前的可重复步骤遇到短暂错误会进入指数退避。扣款请求已发出但响应不确定时，任务转为 `needs_review`，避免 Worker 自动重试造成重复支付。复核任务只读取 Midtrans 状态，将结果收敛为成功、失败或继续待复核。

## 前端与实时更新

- 支付记录通过 `change_log` 和 SSE 实时刷新。
- 支付、任务、账号、注册与登录记录根据浏览器可用高度计算显示条数。
- 表格视口底部与页面容器保留固定间距，窗口缩放和移动端布局变化后自动重新计算。
- GoPay 账号表格在桌面视口内自适应列宽，“操作”表头和按钮不再被横向滚动区截断，窄屏时仍可横向滚动。
- 参考 `iCloud-Privacy-Mail-v2` 接入全局图标文字提示层：纯图标按钮鼠标悬停或键盘聚焦时，优先在图标下方显示中文功能名称，底部空间不足时自动翻到上方。
- 所有任务协议键在页面展示为中文，API 和数据库协议键保持英文。
- 管理员密码、PIN、OTP 与 API Key 等表单字段均使用可见的普通输入框，页面不保留隐藏辅助输入框；提交后的持久化加密规则不变。

## 验证范围

- Snap 主机与路径校验、账号与 PIN 选择、幂等支付创建。
- 支付 OTP 暂停与恢复、两阶段 PIN 授权、远端成功结果落库。
- 不确定副作用转人工复核，复核任务只读更新远端状态。
- 支付 REST API、任务输入 API、SSE 刷新和前端生产构建。
