> 验收日期：2026-08-26

## 本阶段目标

P0 先建立安全、可迁移、可测试的 Python 应用基础，不调用真实 GoPay、Midtrans 和短信接口。旧项目继续保留，新实现全部位于 `gopay-refactor`。

## 已完成

- FastAPI 应用工厂、统一中文错误、健康检查和系统状态接口。
- SQLite WAL、外键、5 秒忙等待、NORMAL 同步和自动检查点。
- Alembic 初始迁移和模型差异检查。
- 账号、号码、支付、任务、批次、OTP 输入、资源租约、实时变更和审计表。
- AES-GCM 敏感字段加密和独立数据库密钥。
- 数据目录 `0700`、数据库与密钥 `0600`。
- Argon2id 单管理员首次设置、登录、会话、CSRF、Origin 和 Host 边界。
- 登录滑动窗口限流和 API 请求体大小限制。
- 旧 JSON/ENV 数据只读预检、确定性 ID、文件摘要和幂等导入。
- Python 3.11 独立虚拟环境和精确依赖锁。
- Ruff、编译、pytest、覆盖率和真实旧数据迁移验收。
